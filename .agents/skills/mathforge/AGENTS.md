# Mathforge project instructions

Use SKILL.md as the entry point. This directory is the editable design and skill package. Runtime specifications are not installed services. The HUD is a synthetic preview. The conjecture remains open.

The root agent owns SKILL.md, the architecture, shared contracts, integration, and the final evidence report. Each delegated task owns disjoint artifact paths. Verification agents must not receive another reviewer's conclusion before submitting their own.

Preserve exact mathematical statements and assumptions. Never promote a result based on model consensus, numerical agreement, or a claim that a checker ran. Keep source data, human decisions, and generated interpretations distinct. Reference evidence by stable artifact revision and hash.

Use work/ for temporary experiments. Keep deliverable references within this package. Do not start persistent research or purchase compute from these instructions alone. All new runtime capabilities must have an actual adapter, current authority, and verification evidence before being described as available.
