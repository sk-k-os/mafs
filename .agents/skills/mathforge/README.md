# Mathforge

Reusable research skill for Birch and Swinnerton Dyer over Q.

Use the repository root README for installation and startup. This package provides an interactive launcher, research method, exact solution contract, six account architecture, candidate evaluations and a synthetic HUD. It does not supply a persistent research runtime or claim a proof.
